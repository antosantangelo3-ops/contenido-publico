# contenido-publico

Solo imágenes **ya aprobadas por Antonella** para publicar en Instagram (@contadora.antonella) a través de la API.
La API de Instagram necesita leerlas desde una dirección pública.

- Nada privado: ni datos de clientes, ni documentos del estudio, ni material sin aprobar.
- Después de publicar, las imágenes se pueden borrar: Instagram guarda su propia copia.
